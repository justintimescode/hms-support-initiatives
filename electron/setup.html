Connect to Jira

KPI Analyzer pulls issue data from Jira Cloud. Enter your Atlassian account email and a personal API token. Your token is stored encrypted on this machine, tied to your Windows login — it is never shared or sent anywhere except Jira.

Need a token? Click “create one here” above to open Atlassian’s API token page in your browser, generate a token, and paste it in. You can change these later from the File → Reconfigure Jira credentials menu.
